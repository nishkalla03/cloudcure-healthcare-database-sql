# 🏥 CloudCure Healthcare Database – SQL Implementation

## 📌 Project Overview

CloudCure Healthcare Database is a university group project developed as part of the **Database Management Systems** course. The project focused on designing and implementing a relational database for a healthcare management system using Oracle APEX.

This repository highlights **my contribution** to the project, which involved developing and testing SQL scripts for data retrieval, analysis, and database object creation.

---

## 👩‍💻 My Contribution

As the SQL developer for this group project, I was responsible for:

- Writing SQL queries for data retrieval and analysis
- Developing subqueries to filter and retrieve specific records
- Creating multi-table JOIN queries
- Using aggregate functions for reporting and summarization
- Creating database views to simplify data access
- Testing and validating SQL statements in Oracle APEX

---

## 🛠️ Technologies Used

- Oracle APEX
- Oracle SQL
- Relational Database Management System (RDBMS)
